whisper.cpp WASM inference benchmark

Manual dev tool, not part of the extension build (Phase 7 known gap: "no benchmarking harness in the repo"). Loads the vendored third_party/whisper-wasm/libmain.js glue directly in a plain page — the same approach used to verify the real binary (see docs/whisper-wasm-provenance.md) — and times repeated full_default calls on synthetic silence. Inference cost is dominated by Whisper's fixed 30 s encoder window (see HANDOFF.md), so silence is representative of timing; it is not useful for checking transcript correctness.

Must be served over http(s), not opened as a file:// URL (the model fetch needs a real origin). The threaded build below additionally needs crossOriginIsolated (COOP/COEP headers) to get SharedArrayBuffer — a plain static server does not set those, so from the repo root run node bench/serve.mjs instead, then open http://localhost:8000/bench/whisper-bench.html.
